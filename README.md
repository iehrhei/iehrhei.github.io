# Ouvroir de Rhei

An open workroom for curiosity: a handmade scrapbook of experiments, essays and things made real.

Live: https://iehrhei.github.io/

No build step. Everything (fonts, sounds, images) is served from this repository, so the site
works without Google Fonts or any other third-party service.

## Publish on GitHub Pages
1. Create a public repository named `iehrhei.github.io`.
2. Upload everything in this folder (including the hidden `.nojekyll` file) to the root of the repository.
3. Settings → Pages → Build and deployment → Source: *Deploy from a branch*, Branch: `main` / `(root)`.
4. After a minute or two the site is live at https://iehrhei.github.io/.

Your other projects keep their own addresses alongside it:
https://iehrhei.github.io/buen-camino/ and https://iehrhei.github.io/opus-void/.
